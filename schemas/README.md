# Order JSON Schema

This directory contains a draft 2020-12 JSON Schema for market order records.
It is based on the canonical `market/types.Order` JSON fields and the order
examples generated by `tools/data_generator.py`.

## Files

- `order.schema.json` - schema for order payloads.
- `examples/valid-limit-order.json` - a standard limit order.
- `examples/valid-iceberg-order.json` - an iceberg GTD order with optional fields.
- `examples/invalid-missing-required.json` - intentionally invalid payload for validator smoke checks.

## Validation

Use any JSON Schema draft 2020-12 validator. For example, with Python:

```bash
python -m pip install jsonschema
python - <<'PY'
import json
from pathlib import Path
from jsonschema import Draft202012Validator, FormatChecker

root = Path("schemas")
schema = json.loads((root / "order.schema.json").read_text())
validator = Draft202012Validator(schema, format_checker=FormatChecker())

for name in ["valid-limit-order.json", "valid-iceberg-order.json"]:
    payload = json.loads((root / "examples" / name).read_text())
    validator.validate(payload)

invalid = json.loads((root / "examples" / "invalid-missing-required.json").read_text())
errors = sorted(validator.iter_errors(invalid), key=lambda error: list(error.path))
assert errors, "invalid example should fail validation"
print("order schema validation passed")
PY
```
